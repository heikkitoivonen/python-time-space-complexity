# concurrent Module

The `concurrent` package groups APIs for concurrent execution.

## Executors and Futures

See [concurrent.futures](concurrent_futures.md) for executor and Future operations,
complexity tables, and examples using thread, process and interpreter pools.

## Interpreters

See [concurrent.interpreters](concurrent.interpreters.md) for creating interpreters, moving data
between them, and cross-interpreter queues (Python 3.14+).
