# xml Module

The `xml` package contains interfaces for parsing and manipulating XML documents.
Operation complexities and examples are documented on the interface pages:

- [ElementTree](xml.etree.elementtree.md) — parsing, searching, building and serializing element trees.
- [DOM](xml.dom.md) — document objects and DOM traversal.
- [SAX](xml.sax.md) — parsing with event handlers.
- [Expat](pyexpat.md) — the Expat parser interface.
